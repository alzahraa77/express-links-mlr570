# Express Links mechanism test

Frozen on 19 November 2026 (Dubai), before running any source-perturbation results. The forecasting results and the link audit below were already available. This is a prospective decision rule for the diagnostic, not a preregistration of the earlier accuracy analyses.

## Link audit

The two selectors use the same minimum candidate distance of three hops. Distances are shortest paths on the symmetrized original graph. I independently recomputed distances and effective resistance from each saved original graph and checked both against the link CSVs. Resistance ranks are computed against all eligible sources for the **same destination**, including ties at the observed value. Raw resistance values should be compared within each dataset only. The audit used the graph outputs generated locally from the replication selector and the same research-mirror source data. Forecast-only typically selected lower-resistance links and had shorter median distances. Many of its PEMS-BAY links still span at least six hops. The accuracy results therefore support predictive rewiring and do not justify explaining forecast-only's gain as relief of high-resistance bottlenecks.

## Primary diagnostic and fixed decision rule

Use the three saved METR-LA seeds for each of the original graph, Express Links and matched random. Keep the learned weights, graph, preprocessing and 60-minute horizon fixed. Test each **Express Links source–target pair on all three models**, including on the matched-random model, whose inserted links go to the same target roads. This estimates the added use of the selected signals under the two rewiring policies. It does not estimate which of the random model's own sources it uses most.

1. **Choose cases and donors without test outcomes.** Keep selected pairs with positive out-of-sample gain from adding the source in the selector's later training block. Use the same held-out origins for all models, scoring only observed targets below the original training-defined low-speed cutoff. Use the result of that cutoff only for scoring, never for choosing donors. For each test origin choose five donor input windows from validation, with the same weekday/weekend class and time of day within 30 minutes. Choose distinct donor dates if possible. Rank eligible donors by standardized Euclidean distance on the destination's 12 recent speeds and original neighbors' current weighted mean speed, with earliest timestamp as the tie-break. Retain only complete observed histories for the source in both the test and donor windows. Do not use future speeds to choose a donor. Perturb just the source channel's 12 recent speeds, preserving timestamp features, graph and other sensor inputs. Use identical donor windows for all arms and seeds. If fewer than five donor dates are possible, drop that case for every arm.
2. **Measure use, not sensitivity alone.** For each case, compute the average absolute error after the five replacements minus its original absolute error. A positive value means replacing the source made the forecast worse. Retain all matched cases equally by reading. Produce per-day error sums and reading counts on the shared sample, using the dataset's recorded target date. Report coverage by sensor and day. If the final sample covers fewer than 15 of the 25 destinations or fewer than seven test days, declare the diagnostic inconclusive.
3. **Fix the pass threshold now.** Express Links passes the source-use diagnostic only if replacing the source increases its error on average and **the lower end of the paired 95% day-bootstrap interval for its added reliance over matched random is greater than +0.01 mph**. Apply that same threshold against the original graph as a second required check. For each contrast, also require a point estimate above +0.01 mph in at least **two of three seeds**. The 0.01 mph margin is a prespecified minimum for this diagnostic, not an operational congestion threshold. Use 10,000 day-bootstrap draws with RNG seed 20261119, reusing each sampled set of days and their multiplicities across all arms and seeds. Within each draw, compute a reading-weighted contrast per seed and average the three paired contrasts. Report the 2.5th and 97.5th percentiles and all three seed estimates. Percentiles reflect test-day variation conditional on the three trained models.
4. **Separate source use from bottleneck relief.** If the primary diagnostic passes, test the baseline model on same-destination control sources at exactly the same original hop count but in that destination's lower half of eligible resistance. Choose the closest positive training-block predictive gain, within the larger of 0.05 mph or 25% of the selected source's gain. Break ties by sensor ID. Apply identical case and donor rules to the high- and low-resistance sources and evaluate only their shared cases. Require the same coverage minimum. A bottleneck-consistent pattern requires the original model to lose more accuracy when replacing the matched low-resistance source than when replacing the high-resistance source, even though those sources have comparable predictive gain. Use the same +0.01 mph threshold, paired day interval and seed rule for that contrast. Insufficient matches make the bottleneck check inconclusive.

## Interpretation fixed before running

- If the primary check passes, say Express Links increased reliance on selected, weakly connected predictive sources in this test. If the bottleneck check also passes, call the pattern **consistent with relief of over-squashing** on METR-LA. Confirm it on PEMS-BAY and isolate the mechanism in a controlled graph before using a stronger causal claim.
- If either check fails or coverage is inadequate, report the result as inconclusive or unsupported for the corresponding claim. Keep **predictive graph rewiring for low-speed traffic forecasting** as the main framing. A passing diagnostic would not change the empirical fact that forecast-only had the lowest mean on the forecasting target metric and mostly used lower-resistance connections.
- Do not tune the margin, donor rule, seed count, resistance groups or published denominator after viewing diagnostic results. Label any alternate results exploratory.
