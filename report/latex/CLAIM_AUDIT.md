# v11 claim and results audit

The manuscript was reviewed against the archived run outputs, experiment notes and source code. No experiment was rerun. The package preserves the full horizon and speed-band exports and the supplementary architecture and event results. The study's numerical results are unchanged. This review checks internal consistency and the scope of the manuscript's claims. It does not constitute a new literature survey or a first-in-literature claim.

| Report section | Evidence checked and how to interpret it |
|---|---|
| Introduction and related work | State the contribution as two implemented selection approaches and their controlled evaluation. Forecasting gains and input-replacement evidence answer separate questions. |
| Methods | Stage 1 updates the resistance score after each added link. Its formula uses the connected component's node count. Stage 2 computes the ridge features and fits the predictive screen on training data, then uses a later training block for ranking. The graph construction procedures differ in how they symmetrize the adjacency and select edges. |
| Stage 1 | Recomputed means and seed standard deviations from 42 real-data runs. On METR-LA, random links reduced total resistance by 36.1% and had mean lead–lag correlation 0.08, yet their overall 60-minute MAE was slightly higher than the original graph's. The jam-warning scores and the speed tolerance at observed events measure different outcomes. |
| Baseline and six-way study | Recomputed results from baseline exports and 36 six-way runs. All modes within a dataset share an evaluation fingerprint. The original Express Links rule passed on PEMS-BAY and failed on METR-LA. Forecast-only leads the shared low-speed target slice on both datasets, with a 0.0046 mph mean lead over ridge-based Express Links on PEMS-BAY. The virtual node leads overall 60-minute MAE on both datasets. |
| Directed links | Compared selected destinations, hops, resistance and ridge scores. Forecast-only and ridge-based Express Links share 21 of 25 destinations on METR-LA and 12 of 25 on PEMS-BAY. The reported resistance percentiles rank against all eligible pairs. These comparisons describe the selected graphs. They cannot attribute the difference in forecast error to source selection alone. |
| Mechanism tests | The week-swap primary condition held for one seed, and the secondary comparison held for zero seeds. The five-donor lower bounds were −0.0057 and +0.0041 mph, below the +0.01 mph gate. The five-donor follow-up was skipped. The two tests use separate rules and measure different contrasts. |
| Model transfer | Checked the DCRNN table against per-seed records. Forecast-only beat the destination-matched random reference on the shared low-speed target slice for all three seeds in both Graph WaveNet and DCRNN on METR-LA. DCGRU is recorded separately as a supplemental architecture check. |
| Tuning | The two-seed validation gain reversed at five seeds. The locked test difference on the primary metric was tuned minus current Forecast-only of +0.0431 mph (95% day interval +0.0211 to +0.0681). The tuned setup beat its matched random control and met the overall MAE limit. It failed the full rule, so the current Forecast-only configuration was retained. |
| Figures and appendices | Rebuilt the generated quantitative figures and appendix tables from the package data. Checked the six-road schematic independently from its weighted example and reviewed the rendered pages. The geographic map is preserved from the prior source package. |

The baseline, Stage 1, six-way, DCRNN and locked-test tables were checked programmatically against the packaged run records, covering 274 numeric entries and 40 paired seed counts. The interval figures read the archived diagnostic and test decisions. These checks verify the reported calculations and the consistency of the article with the available evidence, conditional on the archived runs.

## Highest-value next experiment

If there is time for one experiment, keep the destinations, budget, candidate eligibility, weights and evaluation cases fixed. Vary only the source-selection rule and include several matched random graph draws. This directly addresses the main ambiguity in the current comparison. For a tighter submission, move the geographic maps or the worked example to a supplement if there is a page limit.
